# 落ち物パズルゲーム

JavaScriptで制作した、3マッチ形式の落ち物パズルゲームです。

縦・横・斜めに同じブロックを3つ以上揃えることでブロックを消去します。

通常の3マッチに加えて、**ブロックが消えている間にも次のブロックを配置予約できる**仕組みを実装しており、連鎖が始まった後からさらにブロックを追加して連鎖を伸ばすことができます。

## ゲーム概要

画面下からブロックがせり上がってくる中で、ブロックを配置して消していく落ち物パズルゲームです。

### 基本ルール

- 縦・横・斜めに同じブロックを3つ以上並べると消去
- ブロック消去中にも、次に落とすブロックを各マスに1個まで予約可能
- 予約機能を利用して、連鎖開始後からさらに連鎖を追加可能
- 5個以上のブロックを同時に消すとプレイ時間が増加
- プレイ時間がなくなるか、ブロックが上部まで積み上がるとゲームオーバー

## 制作について

JavaScriptによるゲーム制作の学習として制作した作品です。

パズルゲームとしての基本的な処理に加えて、単純にブロックを揃えるだけではなく、**「連鎖が始まった後からプレイヤーが介入できるゲーム」**を目指して、ブロックの配置予約システムを実装しました。

## 実装した主な機能

- ブロックの配置・落下処理
- ブロックのせり上げ処理
- 縦・横・斜めの消去判定
- 連鎖処理
- ブロック消去中の配置予約
- 制限時間
- 5個以上同時消去による残り時間の追加
- ゲームオーバー判定

## 工夫した点

### 消去中の配置予約

本作品では、ブロックが消えている間にも次に落とすブロックを予約できます。

連鎖が完成してから結果を見るだけではなく、**連鎖の途中に新しいブロックを追加して、さらに連鎖を伸ばせる仕組み**にしました。

プレイヤーがリアルタイムに盤面へ介入できることを、このゲーム独自の要素として意識しています。

### 縦・横だけでなく斜めにも対応

一般的な縦・横方向だけでなく、斜め方向についても3つ以上のブロックが並んでいるかを判定し、消去対象としています。

## 操作方法

| 操作 | キー |
| --- | --- |
| キャラクター移動 | ← / → |
| ブロックを1列せり上げる | ↑ |
| ブロックを落とす | Space |
| ポーズ | A |
| ポーズ解除 | Sキーを少し長押し |

音量バーはマウスドラッグで操作できます。

## 起動方法

`index.html` をWebブラウザで開くことで起動できます。
